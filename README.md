# Sport & Nutrition

Appli perso (PWA) : séances de muscu, circuit abdos chronométré, calories et macros avec scan de code-barres (Open Food Facts), suivi du poids.

Installation sur iPhone : ouvrir le lien GitHub Pages dans Safari, puis Partager → Sur l'écran d'accueil.

Toutes les données restent dans le téléphone (stockage local). Rien n'est envoyé dans ce dépôt.
